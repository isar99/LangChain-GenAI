Create a chatbot that can assist users with planning their daily activities.
The chatbot should be able to understand user input, suggest activities based on user preferences, and help organize their schedule.
It should also be able to provide reminders for upcoming tasks and offer tips for time management.
The chatbot should have a friendly and conversational tone, making it easy for users to interact with.
Additionally, it should be able to learn from user interactions to improve its suggestions over time.

Chatbot Features:
1. Create a good user interface using Streamlit
2. Want my chatbot to store data in a database to keep track of user preferences and past interactions.
3. Implement natural language processing (NLP) capabilities to understand user input and provide relevant suggestions.
4. Allow users to input their daily tasks and activities, and the chatbot will help organize them
5. Send daily task to mail, if user wants to receive it via email.
6. Provide reminders for upcoming tasks and deadlines.
